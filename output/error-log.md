# Error log

Recurring spoken mistakes. **Times** = how many separate sessions this error appeared in.
Rising Times = still fossilizing. Flat Times over 3+ sessions = fixed, move it to the bottom.

Only log errors worth hunting — repeated patterns and B1→B2 blockers. One-off slips don't belong here.

Format: `Date | What I said | Correct version | Why | Type | Times`

**Type** is one of: `article` · `tense` · `pronoun` · `preposition` · `plural` · `word-order` · `pronunciation` · `word-choice` · `question-form`
