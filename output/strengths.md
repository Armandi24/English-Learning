# Strengths

What is actually solid. This file is not encouragement — it's **calibration**.

Two reasons it exists:
1. Knowing what's already working tells you what to *stop* spending session time on.
2. B1 learners systematically underrate themselves and over-focus on errors. That
   distortion wastes practice time on things that are already fine.

Only log something here after it holds up **unprompted, across 2+ sessions.**
A single good sentence is not a strength.

Format: `Date confirmed | What's solid | Evidence`
